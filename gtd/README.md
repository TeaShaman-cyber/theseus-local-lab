# GTD workspace

Минимальный локальный каркас GTD для проекта.

## Поток

```text
inbox → next-actions → done
             ├──────→ waiting-for
             ├──────→ someday
             └──────→ projects
```

## Папки

- `inbox/` — новые мысли и обязательства без прояснения.
- `next-actions/` — конкретные ближайшие действия.
- `projects/` — результаты, требующие нескольких действий.
- `waiting-for/` — то, что зависит от другого человека или системы.
- `someday/` — идеи и возможные будущие действия без текущего обязательства.
- `reference/` — справочные материалы, не требующие действия.
- `done/` — завершённые элементы и короткие evidence-записи.

## Правило

Сначала захватить, затем прояснить. Не превращать каждую мысль сразу в проект.
