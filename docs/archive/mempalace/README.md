# Archived MemPalace material

The files in this directory are historical evidence from the 2026-08-01
MemPalace recovery discussion. They were superseded on 2026-08-27 after
MemPalace became an established active service used by Codex/Lad hooks and the
official Codex plugin.

Do not execute the archived plans or infer current runtime status from their
`pilot`, recovery, clone-volume, or read-only language. Current routing comes
from the active infrastructure registry, the live Compose service, the Codex
configuration, and the current project writer.

The legacy `work/mempalace-pilot` path and `theseus-mempalace:pilot` image label
are retained as runtime compatibility names; their labels do not mean that the
service is currently a pilot.
